# C-suite and PMCRO

The C-suite sets mission, priorities, governance, resource limits, and escalation boundaries. PMCRO O-Mode refines the seed, selects a strategy, and runs the phase lifecycle.

Chiefs are bounded domain leads. Chief-to-Chief dependencies use DomainRequest and ResearchFrame messages routed by the Orchestrator. Chiefs do not call tools directly.

```text
Chief objective → O-Mode → typed phase messages → TrailFrames → executive review
```
