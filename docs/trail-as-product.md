# Trail as a product

The Trail is not only an audit log. It is a verified learning product that turns outcomes into reusable constraints and regression tests.

```text
Trail evidence → earned constraints → preflight checks → fewer repeated failures
```

Store summaries, evidence, tool results, scores, hashes, decisions, and constraints. Do not store private chain-of-thought.

A candidate constraint becomes active only after provenance, scope, enforcement points, confidence, and regression coverage are defined. Laws remain constitutional and require explicit governance changes.

Product outputs include audit reports, session handoffs, replayable evidence, constraint libraries, strategy performance, and evaluation datasets subject to privacy and retention policy.
