# Architecture

```text
C-suite goal and governance
    ↓
PMCRO Orchestrator
    ↓ O-Mode
Planner → Maker → Checker → Reflector
    ↓
Orchestrator decision and Trail
```

## Layers

- **MAF Agent Skills:** skill discovery, progressive disclosure, resources, and scripts.
- **Repository rules:** repository-wide rules under `.agents/rules/`.
- **PMCRO:** laws, typed envelopes, O-Mode, phase routing, approvals, Trails, and checkpoints.
- **C-suite:** executive mission, priorities, resource constraints, risk, and delegation.
- **MCP:** external capability and integration surfaces.
- **CodeAct:** approved execution capability, normally mediated by the Orchestrator.

Only the Orchestrator has operational tool authority. Chiefs and phase agents return structured proposals and results.
