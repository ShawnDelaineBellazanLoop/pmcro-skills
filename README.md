# PMCR-O Skills

A MAF-compatible plugin marketplace for creating, governing, and orchestrating Agent Skills.

## Plugins

- [pmcro-skill-creator](plugins/pmcro-skill-creator/) - Create and validate Agent Skills.
- [pmcro](plugins/pmcro/) - PMCRO framework, O-Mode, typed envelopes, laws, constraints, and Trails.
- [pmcro-csuite](plugins/pmcro-csuite/) - Executive harness with Chief agents for mission, technology, operations, risk, knowledge, and learning.

## Architecture

```text
C-suite goal and governance
    ↓
pmcro O-Mode selects strategy
    ↓
Planner → Maker → Checker → Reflector
    ↓
pmcro decision and Trail
    ↓
C-suite review or next executive objective
```

CodeAct is an approved execution capability used by Maker or other tools; it is not a replacement for PMCRO governance.
